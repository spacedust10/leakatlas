# LeakAtlas

Record-level membership-inference risk atlas: which training records a model leaks, who they belong to,
and whether attack-free proxies (per-sample gradient norm, loss ratio) could have warned in advance.
CIS 545 Data Security & Privacy (UM-Dearborn). Work in progress — see `docs/tool_notes.md` and `docs/architecture.md`.

Clone with submodules: `git clone --recurse-submodules https://github.com/spacedust10/leakatlas`
